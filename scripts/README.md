# OOAI Graph Scripts

Utility scripts for development, testing, and maintenance of the OOAI Graph package.

## Script Categories

- **Development**: Development workflow utilities
- **Testing**: Test management and execution scripts
- **Performance**: Benchmarking and profiling scripts
- **Debug**: Debugging and diagnostic utilities

## Quick Reference

```bash
# Test management
pdm run python scripts/manage_tests.py

# Performance benchmarking
pdm run python scripts/benchmark_algorithms.py

# Debug utilities
pdm run python scripts/debug/graph_analyzer.py
```

## Structure

```
scripts/
├── manage_tests.py                   # Test management utilities
├── benchmark_algorithms.py          # Algorithm benchmarking
├── debug/                           # Debugging utilities
```
