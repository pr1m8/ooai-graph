## Session Guidelines

### What to Log

**Always Include**:
- Objective and context for the session
- Technical decisions with rationale
- Code changes and their impact
- Testing results and coverage
- Issues encountered and resolutions
- Clear next steps

**When to Create New Session**:
- Starting work on a new major feature
- Significant refactoring or architectural changes
- Major bug investigation and resolution
- Performance optimization work
- Integration work with other packages

### Session Organization

**Naming Convention**: `[YYYY-MM-DD] Brief Descriptive Title`

**Status Tracking**:
- **Active**: Currently working on
- **Completed**: Finished with clear outcomes
- **Paused**: Temporarily stopped, will resume
- **Archived**: Completed and no longer relevant
