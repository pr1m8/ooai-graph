# OOAI Graph Examples

Documentation and examples for the OOAI Graph package.

## Example Categories

- **Basic Usage**: Core graph operations and data structures
- **Algorithms**: Algorithm implementations and usage patterns
- **Performance**: Benchmarking and optimization examples
- **Integration**: Integration with ooai-core and other packages

## Quick Start

```bash
# Run basic example
pdm run python examples/basic_usage.py

# Run algorithm examples
pdm run python examples/algorithms/shortest_path_example.py

# Run performance benchmarks
pdm run python examples/performance/algorithm_benchmarks.py
```

## Structure

```
examples/
├── basic_usage.py                    # Basic graph operations
├── algorithms/                       # Algorithm usage examples
├── performance/                      # Performance and benchmarking
├── integration/                      # Cross-package integration
└── visualization/                    # Graph visualization examples
```
